# GlobalLaunch AI v0.6 — Windows 升级与测试

## 从 v0.5 升级（不需要重新申请 DeepSeek Key）

1. 在旧版 PowerShell 按 `Ctrl + C` 停止网站。
2. 解压 `GlobalLaunch-AI-DeepSeek-v0.6.zip` 到**新的**文件夹，不要直接覆盖正在运行的旧版。
3. 只把旧版项目里的 `.env` 复制到新版的 `globallaunch-ai` 目录。**不要发给别人，也不要上传 GitHub。**
4. 进入新版包含 `server.mjs` 和 `package.json` 的文件夹。在资源管理器地址栏输入 `powershell`，按 Enter。
5. 运行：

   ```powershell
   npm.cmd start
   ```

6. 打开 `http://127.0.0.1:3000`。如果仍看到旧页面，按 `Ctrl + Shift + R`。
7. 在顶部或侧栏确认版本 `v0.6`，生成一份报告并确认 `AI DRAFT READY`。

## 新功能的完整演示流程

1. 从「加载示例」生成 Luma Botanics 报告，自动创建 **v1**。
2. 打开侧栏「证据与迭代」。选择「用户访谈」，输入：

   > 访谈了12位目标消费者，其中8位表示成分信息会影响判断。属于非随机便利样本，不能代表整体市场。

3. 在「信息来源」填写：`2026-10-10 内部访谈笔记（12人）`。这是演示样本，不要将其描述为真实调研。
4. 勾选「策略洞察」「证据清单」，可填写「保留原预算和所有渠道，只更新相应的假设与验证计划」。
5. 点击「生成修订草案」，查看左右两侧的旧版与候选新版摘要。
6. 若结果符合期望，点击「采用为新版本」，生成 **v2**。如果结果不满意，点击「放弃草案」，原报告保持不变。
7. 点击「项目历史」的 v1 和 v2 可切换查看；在 v2 点击「对比上一版」可再次查看差异，无须调用 AI。
8. 导出 PDF：v2 的PDF末尾会附上用户新增材料记录和未核验说明。
9. 点击「导出项目备份」，保存 JSON；可在另一个浏览器中通过「导入备份」恢复。

## 设计边界（重要）

- 项目存储在**当前浏览器的 localStorage**，不是云端数据库。不同设备或浏览器不自动同步。清除浏览器数据可能导致丢失，请务必导出 JSON 备份。
- 恢复 JSON 会**替换当前浏览器的全部项目记录**，操作前先备份。
- 目前仅支持手动录入文字与来源描述，不会自动读取PDF、Excel、研究网站或验证引用。不要粘贴真实用户的姓名、联系方式、健康记录等敏感信息。
- 新证据、访谈观察和客户意见都视为**用户提供、未独立核验**，不是经过系统验证的市场事实。
- 定向修订只允许 AI 修改勾选章节；服务器会固定输入的预算总额和渠道选择。
- DeepSeek 修订属于**新的 API 调用**，会消耗模型余额。无密钥时，系统用明确标注的本地模板做演示。
- PDF 使用浏览器打印功能：点击「导出 PDF」，选择「另存为 PDF」；如存在日期与网页地址，请在打印设置中关闭页眉页脚。
- 面向公网时，需要另外规划访问控制、API限额、数据隐私及持久化存储。免费托管不等于可靠的数据存储。

## 故障排查

- `ENOENT package.json`：PowerShell 没进入 `globallaunch-ai` 项目目录。
- PowerShell 拒绝执行 npm：改用 `npm.cmd start`。
- `DEMO MODE`：检查 `.env` 是否已从旧版复制，重启服务器。
- `401`：检查 DeepSeek Key、访问口令或权限；不要发送密钥截图。
- `429`：API 调用频率或余额限制；查看 DeepSeek 控制台。
- 历史为空：如果是新电脑或无痕窗口，需导入之前导出的 JSON。
